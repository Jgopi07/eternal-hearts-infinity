# ✨ Overview

**Eternal Hearts Infinity** is a modern interactive romantic visual novel web application designed to deliver an immersive storytelling experience with:

- 🎭 Animated character dialogues
- 🎵 Dynamic background music
- 🎙️ AI-powered voice narration
- 💫 Smooth cinematic transitions
- 📱 Fully responsive mobile-first design
- ❤️ Emotional story-driven gameplay

The project combines modern frontend technologies with game-like interaction systems to create a premium visual novel experience directly in the browser.

# ⚡ Installation

## Clone Repository

```bash
git clone https://github.com/Jgopi07/eternal-hearts-infinity.git
```

## Navigate to Project

```bash
cd eternal-hearts-infinity
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```
